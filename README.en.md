# Xue Heng's Collected Essays

> Literary criticism, social commentary, and a third category that has no name yet.

This is not a blog, it's a bookshelf. Posts live in separate repositories by theme; this repository only brings them together.

## Contents

The shelf index is generated in the [Chinese README](README.md) and refreshed daily; this English page does not duplicate it.

## Volumes

| Volume | Repository |
| --- | --- |
| Arts criticism | [arts-criticism](https://github.com/frostseclusion/arts-criticism) |
| Social commentary | [social-commentary](https://github.com/frostseclusion/social-commentary) |

## How this page works

It refreshes once a day: it reads every published post from each volume and lists titles and summaries by date. Editing that list by hand will be overwritten at the next refresh.

## 这一页怎么来的

每天自动刷新一次。它会去每个分册里读已发布的文章，按日期排好，把标题和摘要贴到上面那块目录里。手工改那块目录，下一次刷新会被覆盖。

刚发了新文章、这里还没出现的话，等一等就好；想立刻看到，去 Actions 页面手动跑一次。
